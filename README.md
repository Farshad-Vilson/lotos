# چینی لوتوس — وب‌سایت

وب‌سایت رسمی **چینی لوتوس (Lotus Porcelain)**؛ تولیدکنندهٔ قوری و ظروف چینی در اصفهان.

سایت کاملاً فارسی، راست‌به‌چپ و **بدون هیچ وابستگی بیرونی** است — نه فریم‌ورک، نه CDN، نه ابزار ردیابی. همهٔ دارایی‌ها (فونت، تصویر، استایل، اسکریپت) در همین مخزن قرار دارند.

---

## راه‌اندازی سریع

```bash
# ساخت سایت در پوشهٔ site/
node src/build.mjs

# اجرای پیش‌نمایش محلی روی http://localhost:4173
node serve.mjs
```

نیازی به `npm install` نیست؛ فقط Node نسخهٔ ۱۸ یا بالاتر لازم است.

---

## ساختار پروژه

```
├── src/                        ← منبع (قابل ویرایش)
│   ├── build.mjs               ← سازندهٔ سایت؛ همهٔ صفحه‌ها را می‌سازد
│   ├── data/
│   │   ├── site.mjs            ← اطلاعات تماس، اصول، دلایل، پرسش‌ها، شرایط فروش
│   │   ├── products.mjs        ← ۱۵ طرح قوری با مشخصات و فهرست تصاویر
│   │   ├── process.mjs         ← یازده مرحلهٔ تولید، فازها، روش‌ها، کنترل کیفیت
│   │   └── business.mjs        ← الگوهای همکاری، مدل‌ها، سفارش اختصاصی، صادرات، گالری
│   └── assets/
│       ├── css/main.css        ← کل طرح‌نگار (Design System)
│       ├── js/app.js           ← منو، گالری، فیلتر، آکاردئون، فرم‌ها
│       └── fonts/              ← فونت پِیدا (Peyda) با ارقام فارسی
│
├── media/                      ← تصاویر خام
│   ├── products/               ← lotus-<slug>-<شماره>.jpg
│   ├── process/                ← تصاویر مراحل تولید
│   ├── workshop/               ← تصاویر کارگاه
│   └── brand/                  ← لوگو و آیکون‌ها
│
├── site/                       ← خروجی ساخته‌شده (در گیت ذخیره نمی‌شود)
└── serve.mjs                   ← سرور پیش‌نمایش محلی
```

> `src/` منبع است و `site/` خروجی. همیشه `src/` را ویرایش کنید و سپس `node src/build.mjs` را اجرا کنید؛ تغییرات مستقیم روی `site/` با هر بار ساخت پاک می‌شود.

## کارهای رایج

### افزودن طرح جدید

۱. تصاویر را در `media/products/` بگذارید با الگوی `lotus-<slug>-01.jpg`, `lotus-<slug>-02.jpg` و …
۲. یک شیء تازه به آرایهٔ `products` در `src/data/products.mjs` اضافه کنید:

```js
{
  slug: 'gol-aftab',        // همان بخش <slug> در نام فایل‌ها
  sku: 'LT-16',
  name: 'قوری گل آفتاب',
  motif: 'گل‌وبوته',        // نقش
  colors: ['زرین', 'سرخ'],  // رنگ تزئین
  featured: true,           // نمایش در صفحهٔ اصلی
  summary: 'توضیح یک‌خطی برای کارت محصول.',
  note: 'توضیح کامل در صفحهٔ طرح.',
  count: 6,                 // تعداد تصاویر موجود
}
```

۳. `node src/build.mjs` — صفحهٔ طرح، کارت‌ها و منوی «طرح قبلی/بعدی» خودکار ساخته می‌شوند.

### ویرایش متن‌ها

هر بخش داده در فایل خودش قرار دارد:

| فایل | چه چیزی در آن است |
|---|---|
| `src/data/site.mjs` | اطلاعات تماس، آدرس‌ها، اصول «در یک نگاه»، دلایل، پرسش‌های متداول، شرایط فروش، مخاطبان عمده |
| `src/data/products.mjs` | ۱۵ طرح قوری و مشخصات هرکدام |
| `src/data/process.mjs` | یازده مرحلهٔ تولید، سه فاز، روش‌های تولید، ایستگاه‌های کنترل کیفیت |
| `src/data/business.mjs` | الگوهای همکاری، مدل‌های همکاری، سفارش اختصاصی، صادرات، گام‌های زمانی، گالری |

### افزودن مرحله به فرآیند تولید

یک شیء تازه به `processSteps` در `src/data/process.mjs` اضافه کنید و `phase` آن را یکی از سه فاز موجود بگذارید:

```js
{
  n: '۱۲',
  id: 'step-12',
  phase: 'phase-finish',       // phase-prep | phase-fire | phase-finish
  title: 'عنوان مرحله',
  text: 'توضیح کوتاه مرحله.',
  checks: ['مورد بازبینی اول', 'مورد بازبینی دوم'],
  image: 'media/process/lotus-process-XX.webp',
  alt: 'توضیح تصویر برای صفحه‌خوان',
}
```

نوار مراحل بالای صفحه، چیدمان ستون‌ها و شماره‌گذاری خودکار به‌روز می‌شوند.

### تغییر رنگ‌ها و فونت

متغیرهای رنگ و اندازه در ابتدای `src/assets/css/main.css` (بخش `:root`) تعریف شده‌اند:

طرح بر مفهوم **«خاک و آتش»** بنا شده است: سایت از دو حالت چینی ساخته شده —
خاکِ خام و چینیِ پخته — و آتشی که این دو را از هم جدا می‌کند.
**هیچ رنگ سردی در پالت نیست.**

| متغیر | کاربرد |
|---|---|
| `--clay-*` | سطوح چینی: از خاک خام تا سپیدِ پخته |
| `--ink-*` | سیاهِ گرم، برگرفته از لوگو |
| `--ember-*` | **آتش** — تنها رنگ تأکیدی مجموعه |
| `--copper-*` | مس — فقط خطوط مویی و فلز |
| `--kiln-*` | زمینهٔ تیرهٔ کوره برای بخش‌های دراماتیک |

### اجزای امضای طرح

| جزء | توضیح |
|---|---|
| `.fireband` | نوار چهارحالتهٔ خاک → شکل‌گرفته → آتش → چینی، با گذار رنگی واقعی |
| `.hero2` | قهرمان نامتقارن؛ تصویر تمام‌قد تا لبهٔ دید می‌رود |
| `.heat` | نشانگر حرارت هر مرحلهٔ تولید (۱ تا ۵) |
| `.kiln` | زمینهٔ تیرهٔ کوره برای بخش‌های تأکیدی |
| `.ghost-num` | شمارهٔ روحی پشت تیترهای بخش |
| `.grid-products--stagger` | شبکهٔ پله‌ای محصولات به‌جای شبکهٔ یکنواخت |

برای تغییر فونت، فایل‌های `woff2` را در `src/assets/fonts/` جایگزین کنید و بلوک‌های `@font-face` را در CSS به‌روز کنید.

> برای بررسی اینکه پالت هنوز سرد نشده باشد، کافی است در CSS به‌دنبال کدهای شش‌رقمی بگردید و ببینید هیچ‌کدام مؤلفهٔ آبی بزرگ‌تر از قرمز نداشته باشد.

## تصاویر رسپانسیو

برای هر تصویر، دو نسخهٔ سبک‌تر ساخته می‌شود تا موبایل فایل کوچک بگیرد:

```bash
node .dev/images.mjs      # ساخت نسخه‌های ۵۵۰ و ۸۰۰ پیکسلی
```

پس از آن، `addSrcSets()` در `src/build.mjs` به‌طور خودکار `srcset` و `sizes` به
**همهٔ** تگ‌های تصویر اضافه می‌کند (نیازی به دست‌زدن به مارک‌آپ نیست).

| مورد | اندازه |
|---|---|
| تصویر اصلی | ۱۱۰۰ پیکسل |
| نسخهٔ تبلت | ۸۰۰ پیکسل |
| نسخهٔ موبایل | ۵۵۰ پیکسل |
| نشان برند | `mark-140.webp` (۳٫۴ کیلوبایت) |

## نکته‌های فنی

- **فرم‌ها:** سفارشی‌سازی نشده‌اند تا اطلاعات جایی ذخیره شود؛ متن آماده در واتساپ باز می‌شود. برای اتصال به سرور، `data-inquiry` را در `src/assets/js/app.js` به یک درخواست `fetch` تغییر دهید.
- **دسترس‌پذیری:** ساختار `header`/`main`/`footer`، پیوند «پرش به محتوا»، `aria-expanded` روی آکاردئون و منو، فوکوس قابل‌مشاهده، `prefers-reduced-motion`، و پشتیبانی از `forced-colors` (حالت کنتراست بالا). همهٔ هدف‌های لمسی روی موبایل ≥ ۳۲ پیکسل‌اند.
- **بدون جاوااسکریپت:** همهٔ محتوا دیده می‌شود؛ فقط انیمیشن ورود و جعبهٔ نور غیرفعال می‌شوند.
- **سئو:** برای هر صفحه عنوان و توضیح یکتا، `canonical`، `og:image` اختصاصی (برای صفحه‌های محصول: تصویر خود محصول)، و داده‌های ساختاریافتهٔ `Organization`، `Product`، `FAQPage` و `BreadcrumbList`. `sitemap.xml` و `robots.txt` هنگام ساخت تولید می‌شوند.
- **چاپ:** برگهٔ مشخصات محصول و اطلاعات تماس روی کاغذ خوانا است (CSS چاپ در انتهای `main.css`).
- **کش:** سرور پیش‌نمایش با هدر `no-store` سرو می‌کند و به آدرس CSS/JS یک هش محتوا اضافه می‌شود (`main.css?v=…`) تا مرورگر هرگز نسخهٔ قدیمی را نشان ندهد.
